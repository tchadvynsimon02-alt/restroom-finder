# Restroom Finder

Cross-platform iOS and Android app for finding and sharing nearby restrooms.

## MVP features

- Interactive map with nearby restroom markers
- Automatic location lookup and distance calculations
- Searchable restroom list
- Accessibility, fee, and opening-hours details
- Add-restroom flow with photos and notes
- Favorites and directions

## Development

```bash
npm install
npm start
```

Scan the QR code with Expo Go for development on Android or iOS.
